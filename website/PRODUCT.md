# LocalizationHub

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users

Game translators and Arabic localization teams evaluating a workspace for importing, translating, reviewing and exporting game text.

## Product Purpose

Make game dialogue understandable in context and protect syntax while translating. The public website explains the product and offers a real browser-local sample or file editor.

## Positioning

Local-first game localization with speaker/listener/scene context, protected tokens, structured review, English/Arabic presentation and optional Cloud collaboration. Supported engine text extraction is a Windows-app capability, not browser file extraction.

## Operating Context

Browser users open JSON, CSV or PO/POT, or explore the fictional Last Broadcast sample. Browser-local work stays in that profile and needs explicit backups. Teams may choose authenticated Cloud projects.

## Capabilities and Constraints

React/Vite public routes are prerendered and hydrated. Preserve route URLs, factual content, metadata, valid conversion links and keyboard/RTL behavior. This redesign changes public website presentation only; Web App, Admin MFA, project persistence and Radio behavior are out of scope.

## Brand Commitments

The user confirmed on 2026-09-30: retain LocalizationHub name and existing logo, accurate product content, interactive demonstrations, all existing tips/secrets and LH Radio. The visual world can change radically; reject generic, cluttered, repetitive AI-looking composition.

## Evidence on Hand

Real interactive token-validation demo, bilingual context example, editable 24-entry Last Broadcast sample, supported-format guidance, existing legal pages, 74 tips and existing hidden interactions. No invented customers, metrics, testimonials or pricing.

## Product Principles

- Explain the game-localization purpose immediately.
- Show actual behavior, not marketing claims masquerading as evidence.
- Keep file ownership and browser/Windows boundaries honest.
- Preserve Arabic reading quality and access to real actions.

## Accessibility & Inclusion

English/Arabic and RTL, keyboard use, visible focus, adequate contrast, reduced motion and narrow-screen reflow remain required.
