# LocalizationHub

LocalizationHub is a collaborative localization workspace designed for game translation teams.

## Goal

The goal is to make working with localization files easier, safer, and collaborative.

Users will eventually be able to:

- Import localization files.
- Parse translatable text automatically.
- Edit translations in an organized workspace.
- Preserve IDs, variables, tags, and metadata.
- Share projects with other translators.
- Review and track translation changes.
- Work from desktop or web/mobile.
- Export translated data back into supported formats.

## Version 0.1

The first version will focus only on local file processing.

### Features

- Open a JSON localization file.
- Analyze its structure.
- Detect translatable strings.
- Display source text and translation separately.
- Preserve keys, IDs, placeholders, and metadata.
- Edit translations.
- Save the project locally.
- Reopen saved projects.
- Export the translated file.

### Not included yet

- Accounts
- Cloud storage
- Project sharing
- Real-time collaboration
- Mobile/Web client
- AI translation
- Game extraction
- Game injection
- Unreal Engine integration
- Godot integration

## Development Philosophy

Build the core text system first.

Cloud collaboration and game-specific tools will be added only after the local editor is stable.
