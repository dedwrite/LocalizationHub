The toolbox at `E:\all tools for loc` was treated as **read-only**. Nothing was
deleted, renamed, modified, or reorganized. Only file names, READMEs, LICENSE
files, and source were inspected. No unknown/untrusted binary was executed.

## Game-format evidence inspected (read-only)

- **Unreal**: `.pak`/`.utoc`/`.ucas` presence; `sprawl_pak_unpacked/`, `VOIN_*_unpack/` layout.
- **Godot**: `.pck`, `project.godot`, `.tscn`, `.tres`, `.gd`, `.translation`, CSV localization.
- **Unity**: `*_Data/`, `resources.assets`, `globalgamemanagers`, `sharedassets*.assets`.
- **Ink**: narrative JSON with `storyContent`, `inkVersion`.

## Licensing conclusions

- `repak` (Apache-2.0/MIT), `retoc` (permissive), `UAssetAPI` (MIT), and the
  Ink tooling (MIT) are all **license-compatible** for bundling or external
  invocation with NOTICE attribution.
- `UAssetGUI.exe` is a GUI binary of unclear provenance — **avoid**.
- No tool is bundled into LocalizationHub from this inventory in this batch.
  Where a binary parser is genuinely required (pak/utoc/ucas/uasset), the
  architecture treats it as an **optional external adapter** invoked from the
  desktop, with detection, version checks, timeouts, and no shell injection.

## Decision summary

- **Natively implemented in TypeScript (core, browser-safe + testable):**
  Unreal `.locres` reader, Unreal String Table CSV, Unreal FText-like structured
  data, Godot CSV/PO/`.translation`/scene/resource, Unity TextAsset JSON/CSV,
  Unity Localization String Table JSON, Unity Smart Strings, Ink JSON dialogue.
- **External-tool adapters (desktop only, optional):** `.pak` (repak), IoStore
  (retoc), `.uasset` (UAssetDumper). These are discovered/configured, never
  hardcoded to a private path.
- **Avoided:** a generic binary "string grepper" as a primary parser; it is only
  a low-confidence recovery fallback.
