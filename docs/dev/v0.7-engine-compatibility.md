# v0.7 Engine Compatibility Matrix

Status key: **Supported** · **Partial** · **Experimental** · **Detected Only** ·
**Unsupported** · **Encrypted / User Key Required**

This matrix is honest and per-format. "Supported" means a deterministic,
tested, structured extraction path exists. "External tool" means the desktop
adapter invokes a licensed CLI; it is not bundled and not hardcoded to a private
path.

## Unreal Engine

| Format / surface | Status | Notes |
|---|---|---|
| `.locres` (optimized, v2) | **Supported** | Native TS reader (bounds-checked); namespace/key/source. |
| `.locres` (legacy v1, compiled v3) | **Unsupported** | Reported; delegated to external LocRes tool. |
| `.locmeta` | **Detected Only** | Native culture metadata; no text entries. |
| String Table CSV | **Supported** | Key + source-language columns, comment columns skipped. |
| FText / DataTable / DialogueWave JSON (external dump) | **Supported** | Structured analyzer extracts SpokenText/SubtitleOverride with context aliases. |
| `.pak` | **External tool** | `repak` (Apache-2.0/MIT). |
| `.utoc`/`.ucas` (IoStore) | **External tool** | `retoc`. |
| `.uasset`/`.uexp`/`.ubulk` | **External tool** | `UAssetDumper` (UAssetAPI, MIT). |
| Encrypted `.pak`/IoStore | **Encrypted / User Key Required** | Detected; AES key accepted by adapter, never brute-forced, never logged. |
| DialogueVoice grammatical gender/number | **Partial** | Recognized when present in DialogueWave JSON context; not yet a dedicated reader. |

## Godot

| Format / surface | Status | Notes |
|---|---|---|
| CSV localization | **Supported** | First column keys, locale columns, `_` comments. |
| Gettext PO | **Partial** | Routed through existing PO handling; Godot-specific columns not fully surfaced. |
| `.tscn` / `.scn` text resources | **Supported** | User-facing properties only; res://uid paths excluded. |
| `.tres` (text) | **Supported** | Same as scene property extraction. |
| `.translation` (binary) | **Detected Only** | Delegated to external tooling. |
| `.pck` / embedded PCK | **External tool** | gdsdecomp-class tooling. |
| Custom dialogue JSON/CSV | **Supported** | Structured analyzer + user field mappings. |
| Binary `.res` / `.scn` | **External tool** | Not string-grepped. |

## Unity

| Format / surface | Status | Notes |
|---|---|---|
| Unity Localization String Table JSON | **Supported** | Table + locale + keys; Smart String flag retained. |
| TextAsset JSON (dialogue/custom) | **Supported** | Structured analyzer; MonoBeaiour-limited schema flagged low-confidence. |
| TextAsset CSV | **Supported** | Header-mapped to structured records. |
| Smart Strings | **Supported** | Nested selectors/placeholders protected + validated. |
| Ink narrative JSON | **Supported** | `^line` dialogue, `*choice`, speaker prefix, conversation ordering. |
| `resources.assets` / `sharedassets*.assets` / AssetBundles | **External tool** | UnityPy / AssetStudio-class. |
| SerializedFile with stripped type tree | **Partial** | `limited-schema`/low-confidence; review + mapping offered. |
| **Unity injection** | **Out of scope** | Never writes serialized assets. |

## Generic

- Structured JSON/CSV/key-value records: **Supported** via the shared analyzer.
- Binary printable-string scanning: **Experimental** recovery fallback only; never primary.

## Encoding

UTF-8 (with/without BOM) and UTF-16 LE/BE are handled without corrupting
Arabic/CJK/extended Unicode. Regression fixtures include Arabic.
