# LocalizationHub v0.9.5 — Quiet Workflow

This patch deepens the quiet Web App workflow without weakening Local privacy,
Cloud authorization, protected-token safety, or LH Radio.

- Command Palette entry jumps by key/source/translation text (search-gated).
- Recent Local and Cloud project open commands in the palette.
- Calm glossary notes under the translation editor when source terms match.
- Local export checklist covering empty entries, tokens, UI length, review
  queue, and glossary notes — export remains available after review.
- Quiet session progress pulse for newly filled and approved entries.

No database migration, provider, engine, authentication, or Radio behavior
change is included. Windows x64 remains the packaged Desktop target and the
installer is unsigned. Browser copies still depend on site storage, so export
backups remain important. The source repository remains private, so GitHub
release assets require repository access; the website remains publicly usable.
