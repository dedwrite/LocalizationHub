# LocalizationHub v0.8.0 — Web Experience Update

## Highlights

LocalizationHub v0.8.0 brings the browser experience up to the same focused
translation workflow as the desktop editor, while adding a small first-party
radio experience and smarter Admin track handling.

- Native LH Radio across the public website and Web App.
- Refreshed Landing and Download experience.
- Cloud and Local Projects with a polished responsive Translation Workspace.
- Clearer context, protected-token safety, RTL/Arabic presentation, and mobile
  workflows.
- Admin MFA reliability and release regression hardening.

## Native LH Radio

LH Radio is first-party, Admin-managed MP3 playback. The custom LocalizationHub
player supports collapsed and expanded modes, rotating cover art, full-track
playback, seek, volume, mute, previous/next, playlist, and up-next controls.
Playback remains mounted during same-document SPA navigation.

## Smarter Track Ingestion

The Admin Radio workflow can read ID3 metadata, recover embedded cover art, and
analyze duration, codec, bitrate, sample rate, channels, and file size. Supported
Spotify and YouTube links provide metadata suggestions only; Smart Match shows
the evidence for comparing those suggestions with an uploaded MP3.

Optional audio optimization is available when the deployment provides ffmpeg.
Uploading, analysis, metadata import, Smart Match, and playback do not require
optimization support.

LocalizationHub does not rip audio, download Spotify tracks, convert YouTube
videos into MP3, or search for pirated music.

## Web App & Workspace

The Web App now provides a responsive desktop/tablet/phone workflow for Cloud
and browser-local projects. The Workspace includes Entries, Translator, and
Inspector surfaces, protected-token highlighting, context roles, workflow and
quality tools, Search & Replace, Focus Mode, keyboard navigation, and clear
save/recovery states.

## Game Text Extraction

The read-only Game Text Extraction workflow introduced in v0.7 remains
supported. Godot, Unreal, Unity, and Generic Open File compatibility boundaries
remain documented in `docs/dev/v0.7-engine-compatibility.md`; v0.8 does not add
reinjection or round-trip game modification.

## Reliability & Security

Admin email verification and Google Authenticator MFA retain the existing
Super Admin and recent-TOTP protections. Recoverable Radio failures stay inline
instead of taking down the entire workspace. Provider metadata requests use
strict supported URLs, safe redirects, bounded responses, and validated artwork.

## Known Limitations

- Radio media currently uses PostgreSQL-backed storage suitable for the curated
  library; object storage is future scaling work.
- Optional audio optimization depends on ffmpeg/ffprobe availability in the
  deployment image.
- Spotify/YouTube metadata suggestions depend on provider availability and rate
  limits; they are not playback integrations.
- Some deep game binary formats remain partial or external-tool-required as
  documented for v0.7.

## Upgrade Notes

The release keeps the existing project formats and migration path. Cloud and
Local Projects remain available, and existing v0.7 projects continue to open
through the shared Project V3 workflow.
