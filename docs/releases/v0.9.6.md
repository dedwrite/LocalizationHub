# LocalizationHub v0.9.6 — App Parity

This patch tightens Desktop/Web parity without weakening Local privacy,
Cloud authorization, protected-token safety, or LH Radio on the website.

- Speaker and Listener dialogue chips are visually distinct on Desktop and Web.
- DeepL is available in the Web Machine Translation panel through an explicit
  LocalizationHub proxy that does not persist keys or text.
- LH Radio is available in the Desktop app as a quiet floating capsule that
  streams published tracks from the Cloud API.
- The interface language control moves to the public footer and a quiet bottom
  dock on app/desktop shells.

No database migration, engine, authentication, or Admin Radio behavior change
is included. Windows x64 remains the packaged Desktop target and the installer
is unsigned. Browser copies still depend on site storage, so export backups
remain important.

تكافؤ أوضح بين الموقع والتطبيق: بطاقات متحدث/مستمع مميزة، DeepL على الويب عبر

المحلية وصلاحيات السحابة والرموز المحمية كما هي.
