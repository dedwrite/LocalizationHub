# LocalizationHub v0.3.0 - Cloud Foundation & Secure Collaboration

LocalizationHub v0.3.0 is the project's Cloud Foundation & Secure Collaboration milestone.

This release moves LocalizationHub beyond local-only project storage and development collaboration by adding persistent accounts, verified Cloud Projects, project roles, and production-tested secure collaboration.

## Highlights

- PostgreSQL-backed accounts, sessions, and Cloud Projects.
- Email verification.
- Owner, Editor, and Viewer project permissions.
- Cloud team and membership management.
- Viewer read-only enforcement.
- One-time WebSocket authentication tickets.
- Server-authoritative Cloud collaboration permissions.
- Live role changes and membership revocation.
- Secure reconnect identity checks.
- Production-safe stale-socket session resume.
- Shared `@localizationhub/core` architecture.
- Full Cloud collaboration security smoke testing.

## Local-First Remains

Accounts and cloud services are optional for ordinary local work.

Local `.lhproj` projects continue to work without requiring a Cloud Project.

## Collaboration Security

Cloud collaboration now validates project access on the server and re-checks permissions during sensitive operations.

Session reconnects are tied to the authenticated account and current project membership. A different account cannot steal another participant's reconnect credentials.

The release also handles stale sockets that may remain visible as connected behind real-world proxies after a client network interruption.

## Production Validation

The full automated Cloud collaboration smoke suite passed against the production relay before release closure, covering:

- Authentication tickets and replay rejection.
- Cloud hosting and joining.
- Editor writes.
- Viewer write rejection.
- Live Editor/Viewer transitions.
- Cross-account reconnect rejection.
- Legitimate reconnect.
- Post-reconnect edits.
- Live membership removal.
- Removed-member join and resume rejection.
- Anonymous local collaboration regression coverage.

## What's Next

Work that did not need to block this milestone moves to v0.4 and later, including broader localization workflows, terminology and review tooling, additional formats and engines, expanded Cloud management, and future web-client work.
