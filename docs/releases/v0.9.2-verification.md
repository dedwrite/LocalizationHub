## Changes

- Separate physical space for Radio and workspace navigation on Local and
  Cloud, desktop and mobile; no playback, progress-path or tagline changes.
- Fluid Landing section spacing, balanced project grids and compact Local
  open/recent sections. More consistent card, dialog and loading surfaces.
- Clearer source/context/translation hierarchy, grouped speaker/listener
  details and scene rows; suppress exact duplicate scene text in presentation
  only. Canonical context, import/export and stored data remain unchanged.
- Bilingual Landing preview switches the real UI language. Switching back to
  English restores whitespace-surrounded labels; header controls no longer
  overlap the language selector.
- Canonical Desktop release command removes development-only URL/config fields
  without changing production endpoints or local development configuration.
