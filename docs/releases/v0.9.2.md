# LocalizationHub v0.9.2 — Web Experience Polish

This patch refines the website and Web App while preserving local privacy,
Cloud project controls, canonical context, token handling and LH Radio playback.

- A dedicated workspace dock keeps Radio clear of navigation on desktop and
  mobile, including Arabic RTL and touch layouts.
- More balanced Landing sections, cards and Local/Cloud project pages reduce
  oversized gaps while retaining readable text and usable controls.
- The landing preview can switch the real interface between English and Arabic.
- Switching back to English restores whitespace-surrounded labels correctly;
  the language selector no longer overlaps header account actions.
- Speaker/listener details are grouped clearly; scenes have their own row and
  duplicate scene/context text is suppressed without changing stored data.
- Refined editor surfaces, toolbar grouping, entry focus, dialogs and loading
  presentation; shorter reveal animations still respect reduced motion.
- New populated-Radio hit-area tests cover Local and Cloud across Chromium,
  WebKit, phones, tablets and desktop. Existing security/privacy tests remain.

No database migration, new engines, provider functionality or Radio behavior
changes are included. Windows x64 remains the packaged Desktop target; the
installer is unsigned. Browser copies still depend on site storage; export
backups remain important. The source repository remains private, so GitHub
release assets require repository access. The website remains publicly usable.

## العربية

تحسينات للموقع وتطبيق الويب: مسافات أكثر توازناً، وسياق حوار أوضح، وشريط سفلي
يفصل Radio عن أزرار التنقل. تدعم المعاينة التبديل بين العربية والإنجليزية، مع
الحفاظ على خصوصية الملفات المحلية وسلوك المشاريع السحابية والترجمة والتوكنات.

لا يتضمن الإصدار تغييراً لقاعدة البيانات أو لسلوك التشغيل. تنزيل مثبّت Windows
من GitHub يتطلب صلاحية الوصول إلى المستودع الخاص؛ ويبقى الموقع متاحاً للعامة.
