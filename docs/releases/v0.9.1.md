# LocalizationHub v0.9.1 — Local Workspace Parity

The final v0.9.x parity and stabilization release brings the mature translation
workspace to browser-local files and adds permanent, owner-only Cloud Project
deletion in Web and Desktop. It also includes the context and LH Radio fixes
already shipped on main after v0.9.0.

## Local Workspace

- Shared Source/Translation editor, entry list, context, protected-token QA,
  workflow and project overview for Local and Cloud work.
- Auto, Generic, Godot, Unreal Engine and Unity token profiles, with persisted
  manual selection and honest unknown-engine fallback.
- Save locally, keyboard navigation, search, completion statistics and unsaved
  work protection; saved translations, statuses, context and selection reopen.
- Safe in-memory compatibility for existing browser copies; storage is upgraded
  only on explicit Save. JSON, CSV and PO/POT export in their original format.
- English/Arabic UI, independent text direction, RTL and responsive layouts.
- Local projects require no account and are not uploaded or synchronized.
  Explicit Machine Translation sends only current text/context to the selected
  provider; provider keys remain transient.

## Project Management

- Cloud Project owners can permanently delete projects from Web cards/Overview
  and Desktop Overview using an exact-name confirmation dialog.
- Server-enforced ownership: editors/viewers cannot delete; unrelated projects
  remain hidden. Failure preserves the open workspace and unsaved draft.
- A transaction and verified foreign-key cascades remove the project's
  memberships, assignments, comments and activity, and revoke its live rooms.
- Accounts, other projects, Admin/Radio data, original source files, browser
  copies, exported files and Desktop .lhproj files are not deleted.

## Context

- Improved conservative speaker/listener/addressee recognition, including
  explicit receiver fields, listener gender and multiple listeners.
- Preserved dialogue roles through raw import, saved projects and Web/Desktop
  lifecycle; synthetic Caloy → Mark and Sofia → KuyaGrab coverage.
- Stale-Web build protection before Cloud file imports avoids creating projects
  with an outdated open tab after deployment.

## LH Radio

- Collapsed playback progress follows the entire capsule perimeter.
- Rotating translator-oriented taglines remain in the expanded player.
- Existing artwork rotation, English/Arabic, ingestion, SPA persistence and
  public GET/HEAD/Range behavior are preserved.

## Reliability

Expanded Local privacy, legacy persistence, quota-failure, keyboard, context,
Cloud autosave, owner authorization/cascade, Desktop deletion, bilingual,
accessibility and responsive regression coverage. Large Local entry lists remain
virtualized and performance-tested.

## Known limitations

- Windows x64 is the packaged Desktop target; the installer is unsigned and
  Windows may show its normal SmartScreen warning.
- Only English and Arabic UI are provided. No new engines, reinjection,
  round-trip rebuilding, automatic translation or Local cloud sync is added.
- Browser copies are tied to this browser/site/device; clearing or evicting site
  storage removes them. Save explicitly and keep exported backups. Offline
  browser editing requires the app to be loaded first.
- Cloud deletion is permanent, without a Trash/undo service.
- Existing deep binary-format/external-tool limits remain as documented in
  the engine compatibility notes.
- Radio remains PostgreSQL-backed; optional optimization requires deployment
  ffmpeg/ffprobe availability. MT requires explicit external-provider use.
