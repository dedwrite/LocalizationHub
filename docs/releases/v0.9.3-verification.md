## Release contents

- 64 bilingual, context-aware tips across Landing, Local Projects, Cloud
  Projects, editor and review contexts. Tip decks avoid repetition until
  exhausted and change only on explicit request.
- Persistent, optional tip visibility preferences fail safely when browser
  storage is unavailable.
- Honest Local and Cloud resume cards: Local stays browser-only; Cloud remains
  constrained to the current user's server-authorized project list.
- Keyboard-accessible, RTL-safe Friday and footer discoveries add restrained
  personality without replacing product content.
- Responsive spacing and geometry cover desktop, phones and tablets while
  preserving the accepted Native LH Radio behavior.
