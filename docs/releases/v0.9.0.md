# LocalizationHub v0.9.0 — Arabic UI & Engine-Aware Tokens

LocalizationHub v0.9.0 is the final release of the accepted v0.9 feature set.
It adds bilingual English/Arabic UI and engine-aware token profiles while
carrying forward the accepted v0.8 Web Experience, Workspace, and Native LH
Radio work.

## Highlights

- English and Arabic UI with persisted locale choice and reliable RTL behavior.
- Engine-aware token profiles for Auto, Generic, Godot, Unreal Engine, Unity,
  and Unknown paths, with manual overrides and mismatch warnings.
- Shared token protection and extraction semantics across Desktop and Web.
- Accepted Web App, Translation Workspace, Admin MFA, and Native LH Radio
  behavior from v0.8.
- Release hardening across browser, server, frontend, website, and Tauri.

## Known limitations

- Some deep game binary formats remain partial or external-tool-required as
  documented in `docs/dev/v0.7-engine-compatibility.md`.
- Radio media uses PostgreSQL-backed storage; object storage is future scaling
  work.
- Optional Radio audio optimization depends on ffmpeg/ffprobe availability.
- The public release is currently Windows x64; other desktop platforms are not
  packaged in this release.
