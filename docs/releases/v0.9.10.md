# LocalizationHub v0.9.10 — Branded Windows Installer

The Windows installer now uses LocalizationHub's black/lime sidebar, header and application icons instead of the default blue artwork. Instruction pages and buttons retain their standard light Windows appearance.

Application behavior, identifiers, storage locations and upgrade logic are unchanged. All v0.9.9 product improvements remain included.

Download `LocalizationHub_0.9.10_x64-setup.exe` and its companion SHA-256 checksum. The installer is unsigned and may trigger SmartScreen. Export important projects before upgrading. Installation over an existing user installation has not been manually tested.
