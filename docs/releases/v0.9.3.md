# LocalizationHub v0.9.3 — Web Delight

This patch makes the public website and Web App more useful and more personal
without weakening Local privacy, Cloud authorization, protected-token safety,
or LH Radio.

- 64 bilingual, context-aware tips cover Landing, Local Projects, Cloud
  Projects, editor, and review workflows.
- Each tip deck uses a shuffled bag, avoids repetition until exhausted, changes
  only on request, and offers a persistent hide/show preference.
- Local resume cards reopen the latest browser-saved project without uploading
  it. Cloud resume cards remain scoped to the signed-in user and current
  server-authorized project list.
- Progress summaries use honest entry counts and never round incomplete work up
  to 100 percent.
- Quiet Friday and footer discoveries add personality while remaining
  keyboard-accessible, RTL-safe, and visually restrained.
- Empty-space and responsive refinements keep the additions balanced across
  desktop, phones, Safari/WebKit, English, and Arabic.
- Regression coverage exercises optional storage failures, deleted or denied
  Cloud projects, typing stability, focus behavior, mobile geometry, RTL, and
  the existing Local and Cloud workflows.

No database migration, provider, engine, authentication, or Radio behavior
change is included. Windows x64 remains the packaged Desktop target and the
installer is unsigned. Browser copies still depend on site storage, so export
backups remain important. The source repository remains private, so GitHub
release assets require repository access; the website remains publicly usable.

## العربية

يضيف هذا التحديث 64 تلميحاً سياقياً بالعربية والإنجليزية، وبطاقات استئناف
صادقة للمشاريع المحلية والسحابية، ولمسات هادئة تضيف شخصية للموقع وتطبيق الويب.
تبقى ملفات Local داخل المتصفح، وتبقى صلاحيات Cloud تحت تحكم الخادم، ولا يتغير
سلوك LH Radio أو المصادقة أو قاعدة البيانات.

يدعم الإصدار سطح المكتب والهواتف وSafari/WebKit واتجاه RTL. مثبّت Windows x64
غير موقّع، وتنزيله من GitHub يتطلب صلاحية الوصول إلى المستودع الخاص، بينما يبقى
الموقع وتطبيق الويب متاحين للعامة.
