# LocalizationHub v0.6.0

## Web App & Mobile Translation

Use LocalizationHub anywhere: desktop, browser, tablet, or phone.

This release adds browser Cloud Projects, responsive translation editing, workflow and quality tools, team/comments/assignments/history workflows, protocol-compatible collaboration, browser-local JSON, CSV, and gettext PO import/export with IndexedDB recovery, and private operator administration.

### Scope

- `/app` browser application and protected Cloud Project routes.
- Owner, Editor, and Viewer-aware browser editing.
- Search/filter, workflow state, statistics, protected-token warnings, tags, glossary and Translation Memory guidance.
- Comments, assignments, activity/history, restore, and team management surfaces.
- Existing version 2 one-time-ticket WebSocket collaboration path.
- Local browser files stay local until explicit Cloud creation.
- No game-specific extraction, injection, archive, executable, Godot, PCK, Unreal, or LOCRES tooling.

This is release-candidate preparation only. Staging acceptance and production release remain separate operational steps.
