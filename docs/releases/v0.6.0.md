# LocalizationHub v0.6.0

**Release Date:** 2026-08-26

## Web App & Mobile Translation

Use LocalizationHub anywhere: desktop, browser, tablet, or phone.

This release adds browser Cloud Projects, responsive translation editing, workflow and quality tools, team/comments/assignments/history workflows, protocol-compatible collaboration, browser-local JSON, CSV, and gettext PO import/export with IndexedDB recovery, and a complete private operator (Super Admin) administration console.

### Scope

- `/app` browser application and protected Cloud Project routes.
- Owner, Editor, and Viewer-aware browser editing.
- Search/filter, workflow state, statistics, protected-token warnings, tags, glossary and Translation Memory guidance.
- Comments, assignments, activity/history, restore, and team management surfaces.
- Existing version 2 one-time-ticket WebSocket collaboration path.
- Local browser files stay local until explicit Cloud creation.
- No game-specific extraction, injection, archive, executable, Godot, PCK, Unreal, or LOCRES tooling.

## Admin Console (Complete)

### Authentication & Security

- **Email code challenge** with hashed storage, 5-minute TTL, and a 10-attempt limit.
- **TOTP / Google Authenticator** with AES-256-GCM encrypted secret storage.
- **Separate Admin sessions** — 60-minute absolute TTL and 20-minute idle timeout.
- **Recent-TOTP gate** — destructive actions require a fresh TOTP confirmation within 5 minutes.
- **Audit trail** — every admin operation is logged with admin, action, target, success, metadata, IP, user agent, and timestamp.

### Dashboard & Metrics

- Real-time platform metrics: total / verified / suspended users, projects, active sessions, and logical storage bytes.
- Responsive dashboard with metric cards and quick navigation to users, projects, and audit.

### User Management

- List, search, and detail views for all users.
- Suspend / unsuspend (immediately revokes all sessions).
- Verify / unverify email addresses.
- Revoke all active sessions for a user.
- Delete users with safe (membership-only) or destructive (project cascade) options.

### Project Management

- List, search, and detail views for Cloud Projects.
- Delete projects with full cascade (entries, memberships, comments, activity).
- Transfer project ownership (with editor-level access verification).
- Remove members and change member roles.

### Storage Accounting

- Platform-wide and per-user storage breakdown with logical byte calculations.
- Project-level metrics for capacity planning.

### Session Management

- List active sessions per user with expiration times.
- Revoke individual sessions or bulk revoke all.
- 30-second reconnect grace for inadvertent disconnects.

### Audit Log

- Complete audit trail with pagination and action filtering.

## Technical Implementation

### Server-side (`collaboration-server/admin.mjs`)

- **Security:** `bootstrapSuperAdmin`, `requestAdminEmailCode`, `verifyAdminEmailCode`, `beginTotpEnrollment`, `verifyAdminTotp`, `createAdminSession`, `authenticateAdminSession`, `requireRecentTotp`, `writeAdminAudit`.
- **Users:** `listUsers`, `getUser`, `suspendUser`, `unsuspendUser`, `verifyUserEmail`, `unverifyUserEmail`, `revokeAllUserSessions`, `deleteUser`.
- **Projects:** `listProjects`, `getProject`, `changeProjectMemberRole`, `transferProjectOwnership`, `deleteProject`.
- **Metrics:** `getPlatformMetrics`, `getStorageBreakdown`, `getRecentActivity`, `listAuditLog`.

### API routes (`collaboration-server/server.mjs`)

- `GET/POST /api/admin` — dashboard and auth.
- `GET/POST /api/admin/users` and `/api/admin/users/:id` — user management.
- `GET/POST /api/admin/projects` and `/api/admin/projects/:id` — project management.
- `GET /api/admin/storage` — storage metrics.
- `GET/POST /api/admin/sessions` — session management.
- `GET/POST /api/admin/audit` — audit log.
- Auth flow: email code request/verify, TOTP enrollment/confirmation, logout.

### Frontend (`website/src/AdminConsole.tsx`, `adminApi.ts`, `admin-console.css`)

- Multi-page console with a security gate (email code + TOTP), dashboard, users, projects, and audit views.
- Responsive layout across 360px–1440px viewports.

### Database (`004_admin_authorization.sql`)

- `users.site_role` and `users.suspended_at`.
- `admin_sessions`, `admin_totp_enrollments`, `admin_email_challenges`, `admin_audit_log`.
