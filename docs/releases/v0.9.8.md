# LocalizationHub v0.9.8 — Game-First Experience

This release gives LocalizationHub a clearer game-localization identity while
keeping the complete Local, Cloud, Desktop, RTL, protected-token, and LH Radio
experience intact.

- The Landing now leads with game localization and moves through engine
  extraction, preserved dialogue context, protected syntax, the workspace,
  Local/Cloud choices, and Arabic/RTL support in a tighter product story.
- Godot, Unreal Engine, and Unity are presented first, while JSON, CSV,
  gettext PO, and `.lhproj` remain visible as direct file workflows.
- A built-in Northern Gate sample opens directly in the Local Web workspace,
  so the editor can be explored without preparing a file or creating an
  account.
- Public routes gain route-specific metadata, canonical URLs, an Open Graph
  card, `robots.txt`, `sitemap.xml`, and prerendered public-route shells.
- Quiet Clarity workspace tools remain available through the current Command
  Center: recent projects, entry jumps, glossary hints, progress pulse, and the
  export checklist.
- All 74 translator tips and the existing Friday, FAQ, on-device, footer,
  completion, Sunday, and late-night discoveries remain wired and tested.
- The mobile language dock now stays above the workspace navigation instead of
  covering the Tools control on narrow phones.

No database migration, authentication, Admin Radio, or game-extraction parser
change is included. Windows x64 remains the packaged Desktop target and the
installer is unsigned. Browser Local Projects still depend on browser storage,
so exported backups remain important.

## العربية

يمنح هذا الإصدار LocalizationHub هوية أوضح لتوطين الألعاب، مع قصة مرتبة من
استخراج نصوص Godot وUnreal Engine وUnity إلى السياق والرموز المحمية ومساحة
العمل. يضيف مشروع Northern Gate تجريبيًا للمساحة المحلية، ويحسّن قابلية اكتشاف
الصفحات العامة، ويحافظ على التلميحات الـ74 وكل اللمسات الخفية الموجودة، مع بقاء
الخصوصية المحلية والصلاحيات السحابية وLH Radio دون إضعاف.
