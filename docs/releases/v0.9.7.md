# LocalizationHub v0.9.7 — Quiet Clarity

This patch calms the Desktop and Web workspace shell and expands quiet
translator guidance without weakening Local privacy, Cloud authorization,
protected-token safety, or LH Radio.

- The public shell around the product gains quieter depth: soft gradients,
  hero glow, clearer section rhythm, and restrained micro-motion that respects
  `prefers-reduced-motion`.
- Translator craft tips grow across all tip decks, with two quiet discoveries:
  the Local on-device badge and a Sunday daytime completion note.
- FAQ adds practical answers for offline work, machine-translation privacy,
  Arabic/RTL support, and Local backups.
- A hidden localization footnote lives beside the FAQ heading.

No database migration, engine, authentication, or Admin Radio behavior change
is included. Windows x64 remains the packaged Desktop target and the installer
is unsigned. Browser copies still depend on site storage, so export backups
remain important.
