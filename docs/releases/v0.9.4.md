# LocalizationHub v0.9.4 — Quiet Polish

This patch adds restrained Web App polish without weakening Local privacy,
Cloud authorization, protected-token safety, or LH Radio.

- Command Palette (`Ctrl/⌘ + K`) for navigation, workspace actions, export,
  language switching, and opening the shortcuts center.
- Shortcuts Center (`?`) for the core keyboard workflow.
- Deterministic project visual identity marks on Cloud cards, Local recents,
  and Resume cards.
- Richer empty states for projects, search, filtered entries, review-clear,
  and clean quality checks.
- A quiet “Ship it.” completion moment when every entry has text.
- Soft time-of-day greetings and late-night tips without theme changes.
- Page-shaped skeletons for Projects, Workspace, and Admin loading.
- Calm source/translation length cues with overflow guidance.
- Rare behavior-linked discoveries for Friday-night completion and
  after-midnight saves, alongside the existing tips and Easter eggs.
- Soft settle transitions that honor `prefers-reduced-motion`.

No database migration, provider, engine, authentication, or Radio behavior
change is included. Windows x64 remains the packaged Desktop target and the
installer is unsigned. Browser copies still depend on site storage, so export
backups remain important. The source repository remains private, so GitHub
release assets require repository access; the website remains publicly usable.
