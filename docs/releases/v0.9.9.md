# LocalizationHub v0.9.9 — Product Identity

- New dark and lime product identity across the public website, browser editor, Admin surfaces and Desktop interface.
- Refreshed primary, compact and monochrome brand marks, plus browser and Desktop application icons.
- Product-first Home and interactive product demonstrations, preserving Arabic/RTL and reduced-motion support.
- Shared dark/lime account verification and Admin access email styling; authentication and MFA requirements remain unchanged.
- Translator tips no longer appear inside the Web editor inspector; existing tips elsewhere remain available.
- Patched the vulnerable transitive source-map-js and brace-expansion dependencies.

## Windows installer

Download `LocalizationHub_0.9.9_x64-setup.exe`. The companion `.sha256` file provides its SHA-256 checksum.

The installer is unsigned; Windows may show a SmartScreen warning. No signing certificate was added. Existing application identity and storage locations are unchanged. Export important projects before upgrading.

Automated tests cover application logic, server behavior and browser-rendered Desktop workflows. This release has not been verified by installing over a real user installation.

هوية داكنة وليمونية موحّدة، وشعارات وأيقونات جديدة للموقع والدسكتوب، مع تحسين عروض المنتج ورسائل التحقق ودخول الأدمن. حماية الحسابات وMFA وبيانات المشاريع محفوظة دون تغيير. المثبّت مخصص لويندوز x64 وغير موقّع رقميًا؛ صدّر نسخة احتياطية من مشاريعك المهمة قبل التحديث.
