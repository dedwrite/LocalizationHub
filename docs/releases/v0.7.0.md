# LocalizationHub v0.7.0 (DRAFT — not yet released)

> **Status:** draft. v0.7 is **in active development** — the game-extraction
> pipeline is functional for the best-supported formats but not yet complete
> across every deep binary format, and it has not received final human
> acceptance. Published latest remains v0.6.1.

v0.7 introduces **Game Text Extraction**: turn a raw game folder into a
LocalizationHub localization project, read-only, with rich dialogue context and
protected-token preservation.

## What's new

### Read-only game extraction (Unreal / Godot / Unity)

- **Godot** — `.pck` (via GDRE), `.csv`, `.po`/`.pot`, `.tscn`/`.tres`, `.gd`
  (`tr()`/`tr_n()`), JSON "databases", and native `.inkb` story dialogue with
  speaker resolution and cross-locale line-level alignment.
- **Unreal** — `.locres` (Compact + Optimized) and `.locmeta` natively; `.pak`
  (via repak) and IoStore `.utoc`/`.ucas` (via retoc) orchestrated end-to-end.
- **Unity** — serialized assets/`.bundle` (via a UnityPy helper), TextAsset,
  MonoBehaviour/ScriptableObject, Unity Localization tables, Smart Strings,
  and Ink narrative JSON.
- Multi-language files aggregate into **logical entries** with `localeVariants`
  (one row per localization identity, never one per locale copy).

### Generic "Open File" context preservation

Opening an ordinary JSON/CSV/PO file now preserves explicit dialogue context —
speaker, listener, speaker/listener gender, speaker/listener pronouns, multiple
listeners, scene, conversation, node/line identity, voice, portrait — instead of
flattening a rich record into just key + text. Genders and pronouns are only
ever read from explicit fields (never guessed from names or language); ambiguous
field names are surfaced in a Context Mapping review rather than auto-applied.

### Precision

Proven editor/developer/test tooling is excluded from the default project (with
a visible reason and a way to re-include it), while uncertain and runtime
content stays included. Auto-exclusion requires strong evidence.

### Extraction Review

A desktop review workspace with virtualized entries, a searchable Sources panel,
a maximizable Diagnostics panel, Context Mapping (including an Ignore role), and
a source-language selector that previews the selected locale.

## Compatibility

See the internal engine compatibility matrix for the honest per-format status
(SUPPORTED / PARTIAL / EXTERNAL TOOL REQUIRED / DETECTED ONLY). Binary
`.res`/`.scn`/`.gdc`, OptimizedTranslation key recovery, Unity stripped type
trees, and Unreal UE5 `.uasset` remain PARTIAL or external-tool-required.

## Notes

- All extraction is **read-only**: source game files are never modified.
- v0.7 is extraction-first; no engine reinjection is exposed.
