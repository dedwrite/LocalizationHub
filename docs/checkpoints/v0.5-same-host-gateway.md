# v0.5 Same-Host Gateway

## Architecture

The collaboration server can optionally serve the built website from the repository-relative `website/dist` directory. This is opt-in so the default backend behavior remains unchanged and rollback is a runtime flag change.

- Enable with `SERVE_PUBLIC_WEBSITE=1`.
- Build with `npm run website:build`.
- Start locally with `npm run website:serve`.
- The server fails startup clearly if website serving is enabled without a build.

No production routing, DNS, Cloudflare, Render, or production environment configuration was changed.

## Route Ownership

Backend-owned routes always run before website fallback:

- `/api/*`
- `/health`
- `/verify-email`
- `/favicon.ico`
- `/apple-touch-icon.png`
- WebSocket upgrades on the collaboration server

When enabled, the website serves:

- `/`
- `/download`
- `/privacy`
- `/terms`
- other non-backend client routes through `index.html`
- built assets such as `/assets/*` and `/localizationhub-logo.jpg`

Static paths are constrained to the website build directory, reject traversal, use MIME types, and apply no-cache behavior to `index.html` plus immutable caching for hashed assets.

## Compatibility

The existing collaboration WebSocket server, ticket authentication, reconnect protocol, and protocol version are unchanged. `/verify-email` remains backend-owned and continues to post to `/api/auth/verification/verify`. The existing Render relay hostname is preserved.

## Rollback

Omit `SERVE_PUBLIC_WEBSITE` or set it to anything other than `1` to restore the previous backend-only behavior, including the backend 404 for `/`.

The future `api.localizationhub.app` split remains deferred.

## Validation

Gateway unit tests use temporary fixture directories and cover SPA fallback, backend route exclusion, MIME/cache headers, HEAD, traversal protection, and missing-build startup failure. A local enabled-server probe confirmed website pages, backend JSON routes, verification HTML, and the logo asset ownership. No production service was restarted and no production database was accessed.
