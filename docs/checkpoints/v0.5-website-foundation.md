# v0.5 Website Foundation

## Theme

LocalizationHub v0.5 begins the Website & Launch Experience work. Public product messaging describes the released v0.4.0 Translation Workflow & Quality capabilities; v0.5 website development is not presented as a product release.

## Architecture

- `website/` is an independent React, TypeScript, and Vite workspace.
- It does not import or depend on the Tauri desktop `frontend/` application state or `App.tsx`.
- Release and site metadata are centralized in `website/src/config/site.ts`.
- The site uses lightweight pathname routing for the first public pages.

## Pages

- `/` product landing page
- `/download` Windows x64 release information
- `/privacy` preliminary product privacy information
- `/terms` initial product terms
- unknown paths render a deliberate not-found page

## Current Domain Situation

`https://localizationhub.app` currently serves the collaboration backend. Production routing and domain migration were intentionally not changed in this foundation step.

## Website/API Routing

The intended future direction is a public website at the main domain and a clearly separated API host such as `api.localizationhub.app`. That migration is deferred until the website is approved and is not implemented here.

## Brand and Release

The website reuses the existing LocalizationHub lightning favicon asset from `frontend/public/favicon.svg`, copied into `website/public/favicon.svg`. Current public release messaging points to v0.4.0 and its GitHub Release page. No download counts, testimonials, platform claims, or guessed asset URLs are used.

## Non-goals

This website does not implement account/login UI, game extraction, archive extraction, injection, repacking, executable modification, or any game-specific extraction workflow.
