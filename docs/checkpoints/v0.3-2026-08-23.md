### Authentication
- Authentication migrated from in-memory Maps to PostgreSQL.
- Username + email + password registration.
- Passwords stored with scrypt-derived hashes.
- Persistent sessions.
- Session tokens stored as SHA-256 hashes, never raw tokens.
- Login/logout/authentication tested across separate Node processes.
- Frontend authentication UI implemented.
- Frontend session restoration implemented.

### Cloud Projects
- Cloud Projects migrated from in-memory Map to PostgreSQL.
- Ownership isolation preserved.
- Unauthorized foreign project UUIDs are hidden.
- Atomic revision updates implemented in SQL.
- Revision conflicts tested.
- Cross-process persistence tested successfully.

### Email Verification Foundation
- Random verification tokens.
- Only token hashes stored in PostgreSQL.
- Expiration support.
- Resend cooldown protection.
- Single-use tokens.
- email_verified_at persistence.
- Verified account token suppression.
- Verification token cleanup on failed email delivery.
- PostgreSQL verification flow tested successfully.

### Email Delivery
- Resend delivery adapter implemented.
- localizationhub.app verified in Resend.
- DKIM and sending DNS records configured.
- RESEND_API_KEY configured in Render.

- First real LocalizationHub verification email successfully sent through Resend.

### HTTP Email Verification
- POST /api/auth/verification/send
- POST /api/auth/verification/verify
- 429 resend cooldown response.
- 410 expired-token response.
- 503 email-delivery failure response.
- Raw verification token is never returned by the send endpoint.

- Verification happens only after pressing the Verify button.
