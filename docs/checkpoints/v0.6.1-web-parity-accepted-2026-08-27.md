# LocalizationHub v0.6.1 Web Parity — Accepted

## Status

The v0.6.1 Web Workspace Parity & Translator Experience release is accepted following real-device human acceptance on iPhone Safari. The mobile workspace is comfortable and usable, editing and save work, Entries / Editor / Tools navigation is functional, and the previously reported production Safari crash is resolved.

## Web workspace

The browser workspace reaches desktop parity: a three-pane Entries / Translator / Inspector layout with resizable and collapsible panels, focus mode, and locally persisted layout. The Inspector provides Workflow, Quality, Comments, Assignments, History, Tags, Translation Memory, and Glossary. Entries provide counts, search, filters, bulk selection, and bulk workflow actions. The editor provides protected-token highlighting, direction-aware LTR/RTL editing, inline QA, and Jump to Entry. Project Overview, Search & Replace, and a Branded New Project modal are included.

## Mobile workspace

On phones the workspace is a dedicated Entries / Editor / Tools app rather than a stacked desktop layout. The editor is touch-first with an auto-growing 16px translation field, source card with copy, compact workflow buttons, and Previous / Next / Next Untranslated navigation. Entries provide a progress summary, primary filter chips plus "More filters", and a dedicated selection mode. iPhone Safari behavior includes no input auto-zoom, dynamic viewport and safe-area handling, and independent LTR/RTL direction.

## Save reliability

Cloud saves use a single-flight path that resolves draft updates against the latest state immediately and never loses edits made during an in-flight save. Manual Save and debounced autosave round-trip through the same validated path. Legacy Project V1/V2 payloads migrate in memory to V3 on next save.

## Machine Translation Reference

The web Machine Translation Reference uses Gemini / Google AI Studio with Gemini 3.5 Flash-Lite (fastest, default), Gemini 3.6 Flash (balanced), and Gemini 3.7 Flash (quality), with a lower-latency thinking configuration. The API key is held in browser memory only and uses a visually masked Show / Hide text field, avoiding browser credential autofill.
