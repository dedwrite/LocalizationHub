# LocalizationHub v0.6 Web App Foundation

## Architecture

The website remains a separate Vite React application. The browser app uses a focused web boundary in `website/src/appApi.ts` for same-origin bearer-token transport, authentication, Cloud Project access, saves, and verification email requests. Tauri filesystem, dialog, and desktop window behavior remains in the desktop frontend.

The web app reuses `@localizationhub/core` for project statistics and protected-token validation. The desktop `App.tsx` was not imported or redesigned.

## Routes

- `/`, `/download`, `/privacy`, and `/terms` remain public marketing routes.
- `/app` is the authenticated project dashboard.
- `/app/login` and `/app/register` provide browser authentication.
- `/app/projects` lists real Cloud Projects.
- `/app/projects/:projectId` loads and edits a real Cloud Project.

The existing same-host gateway provides direct navigation and refresh fallback while preserving backend-owned `/api/*`, `/health`, `/verify-email`, favicon, and WebSocket behavior.

## Implemented

- Bearer-token session restore, login, registration, logout, current-user display, verification state, and verification resend.
- Real project listing, loading, role display, revision metadata, and project opening.
- Entry browsing, selection, search, previous/next navigation, translation progress, and untranslated awareness.
- Owner/editor editing with viewer read-only enforcement.
- Full-document Cloud saves using `baseRevision`.
- Revision conflict messaging that prevents silent overwrite.
- Draft, Translated, Needs Review, and Approved workflow controls.
- Protected-token quality warnings using core validation.
- Responsive desktop/tablet multi-pane layout and phone single-column editor with touch-friendly controls and bottom navigation.
- Focused pure logic tests for role permissions, immutable editor updates, and conflict state.

## Deliberate omissions for Batch 2

- Browser team/member management.
- Browser assignments, comments, activity history, and restore panels.
- Browser WebSocket collaboration UI.
- Browser tag editing and advanced quality tooling.
